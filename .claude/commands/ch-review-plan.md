I'm about to hand off the plan to a new agent for implementation. Please
reread the plan from scratch for correctness and self-consistency. Check that
the plan is self-contained, and that a zero-context agent won't be confused.
Read the whole plan start to finish (the way a new agent would).

Remove "history-tracking" statements, such as references to previous designs
that were changed, that might be confusing for a new agent. Be on the lookout
for small improvements (typos, bugfixes) and larger, conceptual improvements
(e.g. opportunities to improve interfaces). Are there any open issues to
discuss? Last chance before I start the new agent!

Which plan: usually this is clear from context (we just wrote it together, or
it's named in the command arguments). If it isn't, ASK me rather than guessing.
